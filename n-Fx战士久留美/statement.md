# 久留美的 FX 账户

## 题目描述

久留美是一位FX战士。这一天，她一口气开了 $n$ 笔仓位：第 $i$ 笔仓位投入的本金是 $a_i$，她给这笔仓位加的杠杆是 $b_i$ 倍。

在久留美看来，一笔仓位最终能变成多少钱，就是本金乘上杠杆；而整个账户的最终金额，则是这 $n$ 笔仓位的金额之和：

$$a_1 b_1 + a_2 b_2 + \cdots + a_n b_n$$

请你帮久留美算一算，这个账户的最终金额是多少。

本金可能为负，表示这笔仓位目前处于浮亏；杠杆取正数表示做多，取负数表示做空，取 $0$ 表示这笔仓位没有开。

## 输入格式

第一行是一个整数 $n$，$1 \le n \le 1000$。

第二行包含 $n$ 个整数 $a_1, a_2, \cdots, a_n$，依次表示每笔仓位的本金。

第三行包含 $n$ 个整数 $b_1, b_2, \cdots, b_n$，依次表示每笔仓位的杠杆。

相邻整数之间用单个空格隔开。

## 输出格式

输出一个整数，表示这个账户的最终金额。

## 数据范围

对于全部测试点，保证：

- $1 \le n \le 1000$
- 对于 $1 \le i \le n$，$|a_i| \le 1000$，$|b_i| \le 1000$

## 样例 1

输入：

```text
3
1 4 6
2 1 5
```

输出：

```text
36
```

样例说明：第 $1$ 笔仓位 $1 \times 2 = 2$，第 $2$ 笔仓位 $4 \times 1 = 4$，第 $3$ 笔仓位 $6 \times 5 = 30$，合计 $2 + 4 + 30 = 36$。
