# 恋人不行·世界线

## 题目描述

玲奈子一直坚信一件事：她不可能成为谁的恋人，绝对不行。

然而世界似乎并不打算放过她。某天早晨，她的手机收到一条来自「世界线观测局」的推送：在这条世界线上，一共有 $n$ 位少女，任意两位之间只有两种关系——要么是**恋人**，要么是**「绝对不可能」**。

更麻烦的是，这个世界还额外遵守两条八卦定律：

1. **恋人的恋人也是恋人**：如果 $a$ 和 $b$ 是恋人，$b$ 和 $c$ 也是恋人，那么 $a$ 和 $c$ 必定是恋人。
2. **两条「不可能」会互相抵消**：如果 $a$ 和 $b$ 不可能成为恋人，$b$ 和 $c$ 也不可能成为恋人，那么 $a$ 和 $c$ 反而会成为恋人。

观测局已经记录下 $m$ 条传闻，每条传闻形如「$a$ 和 $b$ 是恋人」或者「$a$ 和 $b$ 绝不可能在一起」。玲奈子想知道：有多少种不同的世界线，能让这 $m$ 条传闻同时成立？

两条世界线不同，当且仅当存在一对少女，她们在两条世界线里的关系不同。答案对 $10^9+7$ 取模；如果这些传闻本身就自相矛盾，那么一条世界线都不存在，请输出 $0$。

## 输入格式

第一行包含两个整数 $n$ 和 $m$，分别表示少女的人数和传闻的条数。

接下来 $m$ 行，每行包含三个整数 $a, b, c$（$1 \le a, b \le n$，$a \ne b$，$c \in \{0, 1\}$）：

- $c = 1$ 表示传闻说 $a$ 和 $b$ 是恋人；
- $c = 0$ 表示传闻说 $a$ 和 $b$ 绝不可能在一起。

同一对少女可能被多次提及。

## 输出格式

输出一行一个整数，表示满足全部传闻的世界线数量对 $10^9+7$ 取模的结果；若传闻自相矛盾，输出 $0$。

## 数据范围

对于全部测试点，保证：

- $1 \le n \le 10^5$
- $0 \le m \le 10^5$
- $1 \le a, b \le n$，$a \ne b$
- $c \in \{0, 1\}$

## 样例 1

输入：

```text
3 1
1 2 1
```

输出：

```text
2
```

样例说明：$1$ 号和 $2$ 号是恋人。$3$ 号可以和他们站在同一边——此时三对关系全是恋人；也可以站到另一边——此时 $3$ 号与另外两人都「绝对不可能」。两种世界线都满足传闻，所以答案是 $2$。

## 样例 2

输入：

```text
3 3
1 2 1
2 3 1
1 3 0
```

输出：

```text
0
```

样例说明：前两条传闻要求 $1, 2, 3$ 属于同一边，于是 $1$ 号和 $3$ 号必须是恋人；但第三条传闻说她们「绝不可能」，两者冲突，没有任何世界线能满足全部传闻，所以答案是 $0$。
